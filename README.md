# YCY-bililive (B站直播间互动控制器)

这是一个为 Bilibili 直播间与 YCY 蓝牙电击器（支持役次元二代电击器协议）设计的实时互动控制端。通过监听直播间的弹幕、点赞、礼物和上舰等事件，自动触发对应强度的物理反馈，并提供可视化的动态波形界面。

## ✨ 核心特性

- **⚡ 实时互动响应**：支持监听 B站直播间的 弹幕触发词、全局点赞连击、礼物赠送、上舰长/提督 等事件。
- **📡 蓝牙无缝连接**：自动搜索并连接 YCY 蓝牙设备，支持断开识别与一键重连。
- **🌊 动态波形渲染**：UI 界面提供真实的物理脉冲波形实时滚动渲染，拒绝枯燥的静态条。
- **🧠 智能并发包络线**：多任务并发时“强度走最高，时间动态增延”，并完美解决了高频点赞导致的强度溢出问题。
- **🎛️ 多格式波形支持**：内置 12 种基础波形（潮汐、连击、节奏等），并完美支持导入自定义 JSON 波形及郊狼 `.pulse` 格式波形文件。
- **📦 独立免安装版**：提供基于 Flet 构建的打包单文件 `.exe`，纯净无控制台黑框。

## 🚀 快速开始

1. 访问 [Releases](../../releases) 页面，下载最新的 `YCY-bililive.exe`。
2. 确保您的 Windows 电脑已开启蓝牙，并打开 YCY 设备电源。
3. 双击运行程序，在左侧输入您的 **B站直播间号**。
4. 点击 **开始监听 B站**，并点击 **自动连接蓝牙** 绑定您的设备。
5. 在左下方详细配置各种事件（弹幕、点赞、礼物、上舰）的 **基强**（基础强度）、**基时**（基础时长）以及 **增时/增强** 逻辑。

## 🎮 触发逻辑说明

* **点赞顺延机制**：为防止直播间高频点赞导致设备时间或强度异常叠加，本程序采用“后台队列顺延”机制，即使观众瞬间连击 50 次，程序也会严格按照设定的时间间隔依次下发电击。
* **剩余时长增量**：当设备正在运行（剩余时间 > 0）时触发新事件，程序会自动读取当前的实际剩余时间，并将新事件的“增时”叠加其上，呈现真实的物理累加反馈。

## 🛠️ 本地开发环境

本程序基于 Python 3 与 Flet 跨平台框架构建。

```bash
# 1. 克隆代码
git clone https://github.com/DT-DT001/YCY-bililive.git
cd YCY-bililive

# 2. 安装依赖
pip install flet bleak blivedm pillow

# 3. 运行源码
python main.py

# 4. 打包可执行文件
flet pack main.py --name YCY-bililive --icon logo\logo.ico --hidden-import bleak blivedm PIL flet win32gui win32con ctypes -y --distpath out
```
